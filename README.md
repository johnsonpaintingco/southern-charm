# Southern Charm Painting Co. — GitHub Pages starter

A responsive, static, SEO-oriented starter website for a North Atlanta painting company.

## Included
- Homepage and core service pages
- About, projects, contact, service areas, and privacy pages
- Draft city pages for Alpharetta, Roswell, and Johns Creek
- Responsive CSS and lightweight JavaScript
- Basic title/meta tags, semantic HTML, JSON-LD starter, robots.txt, sitemap.xml
- Accessible navigation and a contact-form prototype

## Important pre-launch checklist

1. **Domain:** Replace every `YOUR-DOMAIN.example` value in `index.html`, `robots.txt`, and `sitemap.xml` with your real domain. Add canonical URLs to every page after the domain and final URL structure are set.
2. **Contact form:** In `contact.html`, replace `REPLACE-WITH-YOUR-BUSINESS-EMAIL`. The current form opens an email draft; it is not a server-side form and does not store submissions. For a more professional lead flow, connect Formspree, Basin, Netlify Forms (not available on GitHub Pages alone), or a CRM form and test it.
3. **Business details:** Add the actual business phone, email, service boundaries, hours, legal business details, and any verified credentials. Do not publish unverified claims about insurance, licenses, warranties, years in business, or reviews.
4. **Images:** Current images are remote Unsplash sample images. Replace them with original project photos you own or have permission to use. Download and optimize production images locally for reliability, speed, and image SEO. Do not describe stock photos as company projects.
5. **City pages:** Draft pages are included for Alpharetta, Roswell, and Johns Creek. Keep them out of the sitemap until service coverage is confirmed and each page has genuinely useful, unique local content. Delete or noindex pages that are not ready.
6. **Schema:** Update the JSON-LD in `index.html` with the real URL and only factual, verified business details. Consider adding accurate contact information and other appropriate fields once confirmed.
7. **Privacy:** Update `privacy.html` to accurately describe the services and analytics actually used.
8. **SEO QA:** Validate titles, descriptions, canonical URLs, links, sitemap, robots.txt, structured data, mobile layout, page speed, and form delivery.
9. **Google tools:** Verify the domain in Google Search Console, submit the sitemap, and configure analytics/consent appropriately.
10. **GitHub Pages:** In repository Settings → Pages, select deployment from the main branch and root folder (or use GitHub Actions). Commit the contents of this folder to the repository root. GitHub Pages supports static HTML/CSS/JS; there is no PHP/server backend.

## GitHub Pages path note
This starter uses relative links and relative CSS/JS paths so it works from either a user/organization root site or a project site path. The sitemap and canonical domain must still match the actual production domain and URL paths.
